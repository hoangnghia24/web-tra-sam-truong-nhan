# Implementation plan

## Goal

Build a responsive Vietnamese campaign microsite for Trà Sâm Trường Nhân using the provided artwork and the SWOT/TOWS/7Ps deck. A separate Master Prompt was requested but is not present in the workspace; incorporate it when supplied.

## Checkpoints

1. **Source audit** — verify exact paths, locate usable reference, inspect imagery and extract PDF content, record design and content constraints.
2. **Foundation** — establish static site structure, self-host Spectral and Mulish, implement responsive visual system and semantic page structure.
3. **Experience** — build campaign narrative, product transparency, an interactive “Hóa đơn chờ đợi”, a seven-minute pause, and clear next steps without unverified external links.
4. **Verification** — run automated checks, inspect responsive browser rendering and keyboard interactions, fix observed issues, update records.

Each checkpoint requires observed evidence in `TEST_RESULTS.md`, a status update in `CHECKPOINT.md`, and a focused Git commit where possible.
